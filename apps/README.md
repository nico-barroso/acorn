# Apps

Dos aplicaciones independientes que comparten el mismo backend de Supabase. Cada una se construye y ejecuta por separado.

- [`web/`](web/README.md) — Cliente web en Next.js 15
- [`mobile/`](mobile/README.md) — Cliente móvil en Expo / React Native

Cada subcarpeta contiene su propio `README.md` con instrucciones de instalación, variables de entorno y scripts.
